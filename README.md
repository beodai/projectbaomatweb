- Giới thiệu ngắn gọn: Trang web book phòng khách sạn đơn giản, hiệu quả
- Ngôn ngữ sử dụng: PHP, JavaScript
- CSDL: MySQL (MariaDB trong xampp)
- Hướng dẫn cài đặt & chạy chương trình
1️⃣ Yêu cầu môi trường
- XAMPP v8.0+ (Apache, MySQL, PHP ≥ 8.0)  
- Trình duyệt: Chrome, Edge, Firefox  
- Thư viện PHP: `mysqli`, `mbstring`, `gd`, `openssl`, `curl`  
- Hệ điều hành: Windows / macOS / Linux  
2️⃣ Cách import database
1. Mở **XAMPP Control Panel** → bật **Apache** và **MySQL**  
2. Truy cập: [http://localhost/phpmyadmin](http://localhost/phpmyadmin)  
3. Tạo database mới tên: `hotel`
4. Chọn database `hotel` → tab Import → chọn file `.sql` bên trong folder Database → Go
